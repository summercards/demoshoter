## 写记录的四条硬要求

1. **区分退出码、预期故障、非预期脚本错误、未执行项。** 四类分开写，不许混进「通过数」。
2. **真实渲染的用例不能算进无头通过。** 用了真实渲染器就写明渲染器。
3. **「未做」是必填段。** 没做就说没做，不写「后续跟进」这种空话。
4. **不在记录里发明玩法规则。** 发现设计缺口，回去改设计页，不在这里顺手定规则。
